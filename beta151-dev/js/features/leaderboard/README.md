# TOP 30 ჩარჩოს ფაილები

- `frame.js`: საერთო რეიტინგის სათაური, სტატუსი და 30 ჩანაწერის სია მოაქცია ერთ რეალურ კონტეინერში (`#lb-rank-frame`).
- `../../css/leaderboard-frame.css`: ძველი ფიქსირებული სიმაღლის `::before` ხაზი გათიშულია. ახალი ჩარჩოს ქვედა ნაწილი ყოველთვის მოდის 30-ე ჩანაწერის **შემდეგ**, მიუხედავად ეკრანის ზომისა.
- `../../runtime/leaderboard.js`: ქულებისა და TOP 30-ის ლოგიკა არ შეცვლილა; Firebase უცვლელია.

ტესტი: გახსენი „რეკორდები“ და ბოლოში ჩასქროლე. ჩარჩო უნდა დასრულდეს 30-ე მოთამაშის შემდეგ, ხოლო „მთავარ მენიუში დაბრუნება“ ჩარჩოს გარეთ უნდა იყოს.

## 0.16.1f — სწრაფი სქროლის ფონის დაცვა
- `scroll-guard.js` ქმნის ცალკე, ფიქსირებულ გაუმჭვირვალე ფონს (z-index 299) რეიტინგის (z-index 300) უკან.
- `../../css/leaderboard-scroll-guard.css` თიშავს overscroll bounce-ს და რეიტინგის ფონს გაუმჭვირვალეს ხდის.
- გახსნისა და დახურვისას ფონი ავტომატურად ჩნდება/ქრება.
- `frame.js`-ის TOP 30-ის ნამდვილი ჩარჩო უცვლელია.

ტესტი: ტელეფონზე 30-ე რიგამდე სწრაფად გასქროლე და ბოლოში სწრაფადაც გააქანე. თამაშის ფონი ეკრანის ქვემოთ აღარ უნდა გამოკრთეს. დახურვისას ფონი არ უნდა დარჩეს.

## 0.16.1g — სროლის წითელი ღილაკის გაელვება სწრაფი სქროლისას

სწრაფი სქროლისას Android Chrome-ს შეუძლია რეიტინგის scroll layer-ის მიღმა ძველი fixed layer წამიერად აჩვენოს.

- `scroll-guard.js`: `setOpen(true)` რეიტინგის გახსნამდე ჩართავს `pirali-leaderboard-open` კლასს; დახურვაზე `setOpen(false)` აბრუნებს. MutationObserver რჩება დაზღვევად.
- `../../css/leaderboard-scroll-guard.css`: თამაშის canvas, წითელი მაუზერის ღილაკი, მართვის პანელი და HUD **უხილავია მთელი იმ დროის განმავლობაში**, როცა TOP 30 გახსნილია. ამასთან რეიტინგის საკუთარი ჩარჩო და ღილაკები ხილულია.
- `../../runtime/leaderboard.js`: გახსნა და „თავიდან თამაში“ კლასს სინქრონულად ცვლიან.
- `../../menu.js`: „მთავარ მენიუში დაბრუნება“ აჩენს თამაშის UI-ს საჭიროებისას.

ტესტი: რეკორდების გახსნა → ბოლომდე სწრაფი სქროლი, რამდენჯერმე ბიძგით/გაჩერებით → ღილაკი **არ უნდა გაელვდეს**; დაბრუნების შემდეგ მართვის ღილაკი ხელახლა უნდა ჩანდეს.
