# PIRALI Alpha 0.14 — ჩოხატაური / ტური 1 (Playable Visual Prototype)

**სატესტო ვებბმული:** https://piraligame.github.io/pirali/alpha014-level1-demo/

შეიქმნა მხოლოდ ერთი დონის დამოუკიდებელი სათამაშო დემო, რომელიც ნულიდან ხატავს გარემოსა და პერსონაჟებს Canvas-ზე. ეს არ არის ფოტორეალისტური 3D ან კონცეპტ-არტის პირდაპირი სათამაშო კონვერტაცია; იგი არის ინტერაქტიული 2D ვიზუალური საცდელი ეტაპი.

## რას შეიცავს
- ახალი მამაკაცი სიმონა, შავ-შინდისფერი ჩოხის მიმართულება, ზედხედით და სწორად მიმართული სახით (სვლა ქვემოთ → სახე ქვემოთ), ერთიანი ჩოხის კალთით და მოკლე ხელების მოძრაობით.
- სასოფლო ჩოხატაურის წაგრძელებული ბილიკი; ქვები, ბუჩქები, ხეები, ღობეები, ძველი ხის სახლები, ხის ხიდი და ისტორიული ეკლესიის მიახლოებითი ვიზუალური მოდელი.
- ოთხი აქტიური მოწინააღმდეგე: ორი თოფიანი, ერთი ხმლიანი და ოფიცერი, თითოეულს სიცოცხლე და AI.
- მაუზერი, ხმალი, სანადირო თოფი — გასროლის/მოქნევის გრაფიკა, საბრძოლო ზიანი, გადატენვა.
- სიცოცხლე, HUD, რუკა, სამიზნე, სიკვდილისა და გამარჯვების ეკრანები.
- გამარჯვება: დაამარცხე 4 მოწინააღმდეგე, შემდეგ მიდი ეკლესიის შესასვლელთან.
- კომპიუტერი: WASD/ისრები — მოძრაობა; მაუსი — დამიზნება; მარცხენა ღილაკი — სროლა; Space — ხმალი; Q — იარაღის შეცვლა; R — გადატენვა; Shift — დაში.
- ტელეფონი: მარცხნივ ვირტუალური ჯოისტიკი; მარჯვნივ გასროლა, ხმალი, თოფის შეცვლა, დაში. სამიზნე ავტომატურად ირჩევა მხოლოდ სროლისას; დანარჩენ დროს სახე მიჰყვება მოძრაობის მიმართულებას.

## უსაფრთხოება და არქიტექტურა
- დამოუკიდებელი `alpha014-level1-demo/` საქაღალდე, არ ცვლის `/play/`, `/alpha013-graphics-phase1/`, ძველ APK/AAB-ს ან Firebase-ს.
- **არ** აქვს ქულების ონლაინ ჩაწერა ან Firebase-ის კავშირი.
- ვებდემოა, არა Android-ის განახლება და არა Google Play-ის რელიზი.
- გრაფიკის სამომავლო პროგრესისთვის აუცილებელია ხარისხიანი დახატული/რენდერებული გარემოსა და პერსონაჟების ატლასები: 3D-კონცეპტ-არტის რეზოლუცია და დეტალიზაცია ამ Canvas პროტოტიპში ჯერ არ არის.
