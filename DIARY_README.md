# დღიური • DIARY Alpha 0.03

Separate Android planner build on isolated branch. Georgian default, plus Russian, English, Simplified Chinese, Spanish, German and French. Change language in Settings with a compact selector. Offline tasks remain in the same package and SharedPreferences storage, and versionCode is 3.

Build through Actions. Note: Android 0.01 has a different debug certificate, and cannot be directly replaced by a different signed APK without data migration. The workflow debug APK is not the privately signed release build.
