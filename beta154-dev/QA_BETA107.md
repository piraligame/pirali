# PIRALI BETA 1.07 — ტესტირების ანგარიში

**GitHub Actions: PASSED** — [PIRALI BETA 1.07 browser QA](https://github.com/piraligame/pirali/actions/runs/40407944327)

**8/8 წარმატებული ბრაუზერული შემოწმება:** DEV/PLAYER × PC/მობილურის Pixel 7 ემულაცია, თითო რეჟიმზე ძირითადი და გაფართოებული რეგრესიული ტესტები.

- ყველა ტურის მტრების სიძლიერე დამატებით 10%-ით დასუსტდა BETA 1.06-თან შედარებით (HP, სროლის ინტერვალი, მოძრაობა). შემოწმებულია ტურების 1/6/8/9/10 შეტევის მულტიპლიკატორები; მე-11 ტურის გენერლებისა და ჯარისკაცების კოეფიციენტები კოდით განისაზღვრება.
- მე-11 ტურში **5 ტალღა × 10 მტერი**, თანდათანობით მოსვლა, ბატონი — 0; გენერლები — 0, 0, 0, 1, 2; თითო ტალღის საერთო რაოდენობაში შედიან.
- განაწილება **300 + 300 + 400 + 400 + 600 = 2000**; საერთო მაქსიმუმი **5000 + 2000 = 7000**.
- მე-11 ტურის გვირგვინის პირობა: 50 მოკლული და სრული გამარჯვება, სახლის ჭიშკარში შესვლა.
- ყველა ტურზე მაუზერის ვაზნების, სანადირო თოფის ვაზნებისა და გულების შემთხვევითი დროპის ალბათობა +10% წინა ვერსიასთან შედარებით. რუკაზე განთავსებული მაუზერის მარაგებისა და გულების შესაბამისი ფაქტორებიც +10%, რაოდენობა მთელ რიცხვებამდე მრგვალდება. ეტაპ 8-ის სპეციფიკური -15%-იანი სანადირო თოფის დროპი შენარჩუნებულია.
- შენარჩუნებულია მე-6 ტურის ხეების საფარი, სიმონას მიმართ დევნის AI, მყისიერი ტურის გადასვლები, გურული სახლი და დროშის ფინალი.
- PLAYER Firebase PUT-ის სქემა ტესტირებულია მხოლოდ **იმიტირებულ სერვერთან**, არც ერთი სატესტო ქულა რეალურ Firebase-ში არ გაგზავნილა. DEV ონლაინ ქულებს არ წერს.

**ჯერ არ შემოწმებულა:** რეალურ Android ტელეფონზე ხელით სრული გავლა და Firebase-ის რეალურ ბაზაში 5500-ზე მეტი ქულის შენახვის დაშვება (შესაძლოა მიმდინარე სერვერის წესი <=5500 იყოს).
