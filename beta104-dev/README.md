# ფირალი — BETA 1.04: მე-11 ტურის ტალღები

- თითოეულ ტალღას ჰყავს **ზუსტად 20 მოწინააღმდეგე**. პირველ ტალღაში ყველა 20 თავიდანვე ჩნდება.
- ახალი მტერი არ ემატება, სანამ მიმდინარე ტალღიდან ოცივე არ დამარცხდება.
- მეორე ტალღა: ახალი 20 მოწინააღმდეგე, **10%-ით მეტი HP, მოძრაობის სიჩქარე და შეტევის სიხშირე**.
- ყოველ მომდევნო ტალღას სიძლიერე იზრდება ×1.10 წინა ტალღასთან შედარებით.
- ყოველ მეოთხე ტალღაზე გენერალი შედის 20 მტრის რაოდენობაში; მისი გააფთრებისას დამატებით ჯარისკაცებს არ წარმოშობს.
- ბატონი ტალღის 20 მოწინააღმდეგეში შედის; მოკვლისას შეიძლება სიცოცხლე ჩამოაგდოს.
- ტყვიების პერიოდული მარაგი უცვლელია; ქულები — +5 თითო მოკლულზე, მე-11-ის ბონუსი მაქს. 500, საერთო ზედა ზღვარი 5 500.
- ეკრანზე ჩნდება „ტალღა N • დარჩენილი X/20 • სულ მოკლული Y“; ყველა ოთხ ენაზე.
- 1–10 ტურები, წინა Alpha რეიტინგი და Firebase-ის ბეტა ბაზა უცვლელია.
