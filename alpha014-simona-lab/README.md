# PIRALI — Simona Alpha 0.14 Study A

- მარცხენა ფანჯარა არის მოქმედი Alpha 0.13-ის არსებული რენდერი.
- მარჯვენა ფანჯარა არის ახალი, ექსპერიმენტული სიმონას გრაფიკა.

- ფიზიკა, დარტყმის არე, სიჩქარე, HP, ბრძოლა და Firebase არ შეცვლილა.
- არჩეული მხატვრული ხაზი: წელში გამოყვანილი ჩოხა, მოძრავი კალთები, ქაბალახი, უფრო დეტალური გაზირები; ფეხები და ცალკეული ხელები არ არის დამატებული.
- დეველოპერის Alpha 0.14 კოდის ვარიანტი მხოლოდ `feat/alpha-014-work` ტოტზეა.
- დამტკიცებული Alpha 0.13 /play/ და Android-ის ხელმოწერილი ფაილები უცვლელია.
