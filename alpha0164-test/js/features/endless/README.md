# სიმონა უსასრულოდ — მე-11 ბონუს ტური

- `waves.js` — უწყვეტი ტალღები, 100 ცოცხალი მტრის მაქსიმუმი, 12 საწყისი მტერი. ახალი მტერი დაახლოებით ყოველ 0.24–0.9 წამში მოდის; ტალღის ნომერი იზრდება დაახლოებით ყოველ 22 წამში. **ტური არ სრულდება**; მთავრდება მხოლოდ სიმონას დაღუპვისას.
- ყველა სახის მტერი: მსროლელი (`rifle`), ხმლიანი (`saber`), ოფიცერი (`officer`), ბატონი (`landlord`), პერიოდულად რუსი გენერალი (ყოველ მეოთხე ტალღაზე).
- `hud.js` — ტალღა, მოკლული მტრები და ერთდროულად აქტიური რაოდენობა ოთხ ენაზე.
- `../../../css/endless-hud.css` — მობილური HUD.
- სროლის მასალა მუდმივად ემატება; დამარცხებული ბატონი სიცოცხლეს აგდებს.
- **ყოველი მოკლული მტერი, მათ შორის გენერალი, ზუსტად +200 ქულაა**. სტრიქი/მედალი ამ ტურში დამატებით ქულას არ იძლევა.
- `../../runtime/combat.js`: ქულების გამძახებელი `PiraliEndless.onKill`; ძველი 1–10 ტურების ბრძოლა უცვლელია.
- `../../runtime/update.js`: `PiraliEndless.tick`; მე-11-ში ფინალური კარიბჭე ტურს აღარ ასრულებს.
- `../../progression/player-stats.js`: დროის რეკორდი მე-11-ში ნიშნავს **ყველაზე დიდხანს გადარჩენას**, არა ყველაზე სწრაფად გავლას; ახალი მიღწევები „სიმონა უსასრულოდ“ და „100 მტერი“.

ეს არის მხოლოდ `alpha0163-test/` DEV ტესტი. Firebase-ში ქულები არ იწერება.

- `outcome.js` — სიკვდილის შემდეგ ბონუს ტურის შედეგის წარწერა; რეიტინგი და „კიდევ სცადეთ“ უცვლელია.
- მე-11 ტურში შესვლისას სიმონას სიცოცხლე და მაუზერის ტყვიები სრულად აღუდგება, რათა ბონუს ბრძოლა სამართლიანად დაიწყოს.
