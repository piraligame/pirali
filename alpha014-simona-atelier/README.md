# PIRALI / სიმონას Alpha 0.14 Atelier F — სამი ახალი მოძრავი მოდელი

**სატესტო ბმული:** https://piraligame.github.io/pirali/alpha014-simona-atelier/

## რატომ შევქმენით
Study E-ში დამატებული მორთულობის ხაზები ზედაპირული, ხელოვნური და უძრავი იყო; მომხმარებელმა მკაფიოდ უარყო. Atelier F-ში **შევქმენით რეალურად ახალი სრული ტოპ-დაუნ 2D პერსონაჟის რენდერები** — არა წინა სიმონაზე მიძერწილი უძრავი ხაზები.

## შედარება
- **0 — Study D (დამტკიცებული)**: Alpha 0.13-ის ზუსტად შენარჩუნებული სიმონა + Alpha 0.14-ის დადასტურებული მაუზერი, ხმალი და სანადირო თოფი.
- **A — ისტორიული სიმონა:** ჩოხის ბუნებრივი მოცულობა, ნაჭრის ტექსტურა, უფრო გამოყვანილი გაზირები, დინამიკური ერთიანი ქვედა ნაწილი.
- **B — კინემატოგრაფიული სიმონა:** უფრო მუქი ბუნებრივი მატერია, რბილი შუქ-ჩრდილი, დეტალური კეფა/სახე და სხეულთან მოძრავი ნაოჭები.
- **C — ბრძოლის ველიდან:** მებრძოლის გამძლე ჩოხა, ტყავის ჩასადები, სწორი ერთიანი ბოლო და მოქნილი მოკლე სახელოები.

ახალ A/B/C მოდელებში ფეხები, ჩოხა, ტანი, სახელოები და თავი კუთხისა და ნაბიჯის ფაზის მიხედვით იხატება. თავი/სახე ყოველთვის ლოკალურ -Y მხარესაა; სამხრეთით მიმართვისას სახე ეკრანის ქვემოთ გადადის. იდაყვები არ ჩანს. „მაკრატლისებრი კუდი“ არც ერთ ვარიანტში არ გვაქვს: ყველა ქვედა კიდე ერთიანი, კვადრატული ფორმისაა.

**სამივე ახალი ვარიანტი იყენებს იმავე Study D-ის დამტკიცებულ მაუზერის, ხმლისა და თოფის გამოსახულებებს**, არ ცვლის საბრძოლო ანიმაციის მექანიკას.
