# PIRALI BETA 1.03 DEV

Web: https://piraligame.github.io/pirali/beta103-dev/?v=beta103

### New PC controls
- WASD or Arrow keys move; diagonal movement normalized in the original gameplay update.
- Space or Z fires Mauser, X swings sword, C dashes (მოი აგერ!), P/Escape pauses.
- Desktop mouse: hold and drag in the left half for movement, left-click on game canvas shoots, right-click on game canvas swings sword, middle-click dashes; existing weapon buttons also click.
- Desktop hints appear only on fine-pointer devices. Touch joystick and touchscreen action buttons remain unchanged.
- Releasing a key, losing focus or switching tabs resets held movement to avoid stuck walking.

### Isolation
- Same main gameplay and 11 stages as Beta 1.02; only desktop controls and version text changed.
- DEV stage chooser 1–11, immortality and boss jump retained; all Firebase writes prohibited.
- Old Alpha 0.15 /scores and its Google Play application remain unchanged.

### QA status
Automated browser smoke checks and targeted input tests are documented separately when complete. Full natural 11-stage human playthrough on a real Android phone is NOT claimed unless actually performed. No Android APK/AAB built.
