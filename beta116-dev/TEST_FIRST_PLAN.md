2. GitHub-ის `alpha015-play/`, სხვა ოფიციალური სათამაშო ფაილები და მარკეტში არსებული APK/AAB **არ განახლდეს**, სანამ მოთამაშე თვითონ არ დაადასტურებს, რომ DEV ტესტი ბოლომდე დახვეწილია.
3. Firebase-ის მოქმედი ონლაინ ქულები **არ წაიშალოს, არ გადაეწეროს**. DEV ქულები მხოლოდ ადგილობრივ საცავში რჩება; ონლაინ რეიტინგი DEV-ში read-only.
4. ყოველი ახალი მოდულის შემდეგ შეამოწმე: ექვსივე ტურის მუშაობა, მობილური მართვა, რეიტინგი, ოთხივე ენა, შესრულების სიჩქარე და ძველი ფუნქციების შენარჩუნება.
5. **საბოლოო Alpha განახლება / სათამაშო GitHub / APK / AAB** მხოლოდ **ცალკე დადასტურების შემდეგ** მზადდება DEV-ში მიღებული და შემოწმებული მდგომარეობის საფუძველზე.

## ამ მომენტში GitHub-ზე არსებული ფუნქციები

- **ექვსივე ტური**, მათ შორის `სიმონას ჯოჯოხეთი`: მე-5 ტური სრულდება გენერლისა და ბატონის შემდეგ ეკლესიაში შესვლით, მე-6 — ეშმაკის შემდეგ ცეცხლიან კარიბჭეში შესვლით.
- **მე-6 ტური:** ჯარისკაცები შემცირებულია უკანასკნელ ცვლილებამდე არსებული რაოდენობის 40%-მდე და გზაზე გაფანტულია; ბატონები ცალკეა, სიცოცხლეს ტოვებენ; ეშმაკი აგდებს 5000 ქულიან მოსაგროვებელ გულს; ჯამური მეექვსე ტურის ქულა მაქსიმუმ 5000-ია.
- **კარიბჭე:** `ჯოჯოხეთის ცეცხლოვანი კარიბჭე`, რჩება ეშმაკის სიკვდილის შემდეგაც.
- **ხმალი:** **ზუსტად Alpha 0.15 სათამაშო ვერსიის `swordSwing()`** — ჩვეულებრივი cooldown `34 × 0.8 = 27.2` კადრი, კომბო `24 × 0.8 = 19.2` კადრი, კომბოს ფანჯარა `30` კადრი; **1.5 წამის შეზღუდვა გაუქმებულია**.
- **TOP 30:** რეიტინგში მხოლოდ 30 ადგილი, თითო მოთამაშის საუკეთესო ქულა, ⛪ მე-5 და ✝️ მე-6 ტურის მიღწევები. ჩარჩო მოიცავს მთელ 30 მოთამაშეს.
- **დასრულების შედეგები:** გამარჯვებისა და მარცხის შემდეგ საკუთარი **ამ კონკრეტული თამაშის** ადგილი ჩანს, თუნდაც 30-ეულის მიღმა. არის `კიდევ სცადეთ` ღილაკი ახალი პირველი ტურიდან თამაშისთვის.
- **პირადი სტატისტიკა:** საუკეთესო დრო ექვსივე ტურში, მიღწევები `მეექვსე ტური` და `ჯოჯოხეთი`.
- **Android მობილური რეიტინგის UI:** ფონის წამიერი გამოჩენის პრობლემაზე გაკეთებულია კლასით დამალვა `pirali-leaderboard-open`, მათ შორის წითელი სროლის ღილაკის; ეს **აუცილებლად ხელახლა უნდა შემოწმდეს რეალურ ტელეფონზე**.
- **ენები:** ქართული (ნაგულისხმევი), US ინგლისური, რუსული და ჩინური.
- **ქვედა ვერსიის წარწერა:** `PIRALI • ALPHA 0.16.1 DEV`.
