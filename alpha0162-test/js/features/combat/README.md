# ხმლის მოძრაობა — ზუსტად Alpha 0.15-ის ვერსია

**კოდის წყარო:** `alpha015-play/js/runtime/combat.js` (უშუალოდ `swordSwing()` ფუნქცია).

`js/runtime/combat.js`-ში Alpha 0.15-იდან გადმოტანილია ფუნქცია **უცვლელად**:
- ჩვეულებრივი cooldown: `34 × 0.8 = 27.2` თამაშის კადრი
- კომბოს cooldown: `24 × 0.8 = 19.2` თამაშის კადრი
- კომბოს ფანჯარა: `30` თამაშის კადრი
- ჩვეულებრივი ხმლის ანიმაცია: `22` კადრი; კომბოს: `16`
- ხმლის მოქნევის ეფექტი, დაზიანება, ჰიტბოქსი და parry: Alpha 0.15-ის ანალოგიური.

**1.5-წამიანი რეალური დროის შეზღუდვა ამოღებულია** და `sword-cooldown.js` აღარ იტვირთება. ეს ფაილი რეპოზიტორიიდანაც ამოღებულია, რათა ორი ურთიერთსაწინააღმდეგო მექანიკა აღარ იყოს.

`js/runtime/game-init.js` კვლავ ასუფთავებს `swordCD`-ს ახალი თამაშის დაწყებისას.
