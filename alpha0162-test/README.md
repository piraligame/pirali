# ფირალი — PIRALI Alpha 0.16.2 DEV

**ახალი 10-ტურიანი ვებტესტი:** https://piraligame.github.io/pirali/alpha0162-test/

**დეტალური ტესტის გეგმა და ფაილების რუკა:** [TEN_STAGE_DEV_PLAN.md](TEN_STAGE_DEV_PLAN.md).

**მთავარი წესი:** ჯერ DEV ტესტი და დახვეწა, შემდეგ მხოლოდ მომხმარებლის ნებართვით სათამაშო და Google Play განახლება. `alpha0161-test`, `alpha015-play` და Firebase-ის არსებული ქულები უცვლელია.

## ფაილების მთავარი საქაღალდეები
- `js/config/` — ათი ტურის სახელები, ბალანსი, იარაღები
- `js/runtime/` — საერთო თამაში, მოძრაობა, საბრძოლო სისტემა, რეიტინგი
- `js/features/stages/` — სპეციალური 8-ე და 9-ე ტურის ცალკე მექანიკები
- `js/features/hell/` — მე-10 ტურის ცეცხლიანი გარემო და ეშმაკი
- `js/progression/` — დროები, პირადი მიღწევები, checkpoint
- `css/` — მობილური დიზაინი, TOP 30-ის ჩარჩო, შედეგის ეკრანი
- `assets/` — ხატულები და მედია

ამ ვერსიის ფაილები გრაფიკული და ლოგიკური მრავალმოდულიანი DEV ტესტია; სრული მობილური სათამაშო QA ჯერ არ ჩატარებულა.
