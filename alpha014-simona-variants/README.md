## დამატებითი ვარიანტები
0. **Study D (დამტკიცებული)** — ყოველგვარი დამატებითი კოსტიუმის დეტალების გარეშე.
1. **A / კლასიკური** — მსუბუქი ნათელი ნაკერები, გაზირების გაპრიალება, სარტყლის დეტალები.
2. **B / მებრძოლი** — მუქი ტყავის აქცენტები, გაცვეთილი ქსოვილის ძალიან მცირე დეტალები.
3. **C / დახვეწილი** — სიმეტრიული ოქროსფერი ხაზები, სადა ისტორიული სარტყელი.

ყველა ვარიანტი იყენებს ერთსა და იმავე Simona renderer-ს და იგივე სამი იარაღის ვიზუალურ ფუნქციებს. დეკორი დახატულია ძირითადი პერსონაჟის შემდეგ და იარაღის წინ. ამიტომ არ ცვლის მოძრაობას, ზომას, საბრძოლო ლოგიკას, ჰიტბოქსს, ქულას, Firebase-ს, APK/AAB-ს.
