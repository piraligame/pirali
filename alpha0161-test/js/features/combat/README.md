# PIRALI Alpha 0.16.1 — ხმლის cooldown

**ხმლის ხელახალი მოქნევა შესაძლებელია ზუსტად 1.5 წამის (1500 მილიწამის) შემდეგ.**

- `sword-cooldown.js` — რეალური დროის შემოწმება `performance.now()`-ით. ჩვეულებრივ და კომბო მოქნევაზე ერთი და იგივე დაყოვნებაა.
- `../../runtime/combat.js` — ყოველ მოქნევამდე `ready()`-ს ამოწმებს და წარმატებულ მოქნევაზე `start()`-ს იძახებს.
- `../../runtime/game-init.js` — ახალი თამაშის დაწყებისას cooldown-ს ასუფთავებს.
- მოქმედებს ყველა ტურიდან; ხმლის ანიმაცია, ზიანი და ტყვიის აცილება არ იცვლება.
- `swordCD=90` არის მხოლოდ ძველ სისტემასთან თავსებადობის მნიშვნელობა (90 კადრი ≈ 1.5 წამი 60 FPS-ზე); ნებართვას აღარ აკონტროლებს კადრები, მხოლოდ დრო.

**ტესტი:** ორჯერ ზედიზედ შეეხე ხმალს — მეორე მოქნევა არ უნდა მოხდეს. 1.5 წამის გასვლის შემდეგ ხმალი ხელახლა უნდა ამუშავდეს.

კომბოს ფანჯარა გაზრდილია დაახლოებით 2 წამამდე, რომ 1.5-წამიანმა cooldown-მა კომბო მთლიანად არ გააუქმოს. მოქნევის ანიმაცია და ზიანი უცვლელია.
