# TOP 30 ჩარჩოს ფაილები

- `frame.js`: საერთო რეიტინგის სათაური, სტატუსი და 30 ჩანაწერის სია მოაქცია ერთ რეალურ კონტეინერში (`#lb-rank-frame`).
- `../../css/leaderboard-frame.css`: ძველი ფიქსირებული სიმაღლის `::before` ხაზი გათიშულია. ახალი ჩარჩოს ქვედა ნაწილი ყოველთვის მოდის 30-ე ჩანაწერის **შემდეგ**, მიუხედავად ეკრანის ზომისა.
- `../../runtime/leaderboard.js`: ქულებისა და TOP 30-ის ლოგიკა არ შეცვლილა; Firebase უცვლელია.

ტესტი: გახსენი „რეკორდები“ და ბოლოში ჩასქროლე. ჩარჩო უნდა დასრულდეს 30-ე მოთამაშის შემდეგ, ხოლო „მთავარ მენიუში დაბრუნება“ ჩარჩოს გარეთ უნდა იყოს.
