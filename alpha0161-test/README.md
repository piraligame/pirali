## სად რა არის
- `index.html` — მხოლოდ ეკრანის HTML და მოდულების ჩატვირთვა.
- `js/runtime/world.js` — ტურის გენერაცია, მტრები, ბოსები, ინვენტარი.
- `js/runtime/combat.js` — ჯოისტიკი, „მოი აგერ!“, ხმალი, სროლა.
- `js/runtime/update.js` — მოძრაობა, ეკლესიაში შესვლა, ცეცხლიანი კარიბჭე.
- `js/features/hell/` — მეექვსე ტურის *ექვს ცალკე ფაილად* დაყოფილი ვიზუალები და ბონუსი.
- `js/runtime/leaderboard.js` — TOP 30; ⛪ მე-5 ტური; ✝️ მე-6 ტური.
- `css/leaderboard-milestones.css` — რეიტინგის ნიშნების დიზაინი.
- `js/progression/player-stats.js` — ექვსივე ტურის დრო და ორი მიღწევა: „მეექვსე ტური“, „ჯოჯოხეთი“.
- `js/config/levels.js` და `data/levels.json` — ტურის სახელები ოთხ ენაზე.
- `js/i18n.js` — ენის ტექსტები და 30-ეულის სათაური.
- `js/preview-controls.js` — მხოლოდ დეველოპერული ტესტის მენიუ.
- `assets/` — მედია და იკონები; `css/` — სტილები.

## რეიტინგის წესები
რეიტინგში ჩნდება **მხოლოდ საუკეთესო 30 მოთამაშე**. თითო სახელი ერთხელ ჩანს, მისი უმაღლესი ქულით. მიღწევები (⛪/✝️) ინარჩუნებს ყველა წინა ჩანაწერის მაქსიმალურ პროგრესს და არ ქრება ნაკლები ქულით დასრულებისას. თუ მოთამაშე საუკეთესო 30-ეულში ვერ მოხვდა, მის ქულასა და ნიშნებს რეიტინგის ეკრანი ცალკე აღარ გამოიტანს; საკუთარი შედეგების ნახვა შესაძლებელია „ჩემი სტატისტიკა“-ში.
⛪ — მეხუთე ტურის დასრულება და ეკლესიაში შესვლა; ✝️ — მეექვსე ტურის გავლა (ეშმაკის მოკვლა + კარიბჭეში შესვლა).
არსებული Firebase ჩანაწერები არ იცვლება. ძველი `level:5,win:true` ⛪-ს ნიშნავს; `level:6,win:true` ორივე ნიშანს აჩვენებს.

## უსაფრთხო ტესტირება
მოქმედ თამაშს არ ვცვლით. DEV ვერსია Firebase-ში **არ წერს**. ტესტში დასრულებული თამაშის ქულა მხოლოდ მოწყობილობაზე ინახება და რეიტინგში 🧪 ნიშნით ჩანს; ოფიციალურ რეიტინგში მოსახვედრად მოგვიანებით გამოქვეყნებულ ვერსიაში თამაშია საჭირო.
