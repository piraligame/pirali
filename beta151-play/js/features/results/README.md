# ფირალი 0.16.1 — შედეგის ეკრანის მოდულები

- `run-rank.js` — თამაშის დასრულების ან სიკვდილის ეკრანზე **ამ კონკრეტული ცდის** ადგილი ყველა მოთამაშის შორის. TOP 30-ის შეზღუდვა მხოლოდ საერთო რეიტინგში რჩება.
- `retry.js` — „კიდევ სცადეთ“ ღილაკი, რომელიც ახალ თამაშს პირველი ტურიდან იწყებს.
- `../../../css/result-screen.css` — შედეგის ბლოკისა და ღილაკის სტილები.

### შეფასების წესი
მოთამაშის მიმდინარე ქულით ადგილი გამოითვლება ყველა სხვა მოთამაშის **საუკეთესო** ქულის წინააღმდეგ, სახელის მიხედვით დუბლიკატების გაერთიანებით. საკუთარი წინა, უფრო მაღალი რეკორდი შედარებაში დროებით ამოიღება, რომ „ამ ცდის ადგილი“ ზუსტად აჩვენოს. თანაბარი ქულები იმავე სახელის სორტირებით განისაზღვრება, როგორც რეიტინგში.

დეველოპერული ვერსია Firebase-ს მხოლოდ კითხულობს. მიმდინარე DEV შედეგი ინახება მხოლოდ ამ ტელეფონზე; ოფიციალურ რეიტინგში არ იგზავნება. თუ სერვერი არ პასუხობს, ჩნდება **სავარაუდო** ადგილი ადგილობრივი ქეშით. 0-ქულიან და შენახული ტურის გაგრძელებით მიღებულ შედეგს ადგილი არ ენიჭება.

ღილაკი მუშაობს მარცხის და გამარჯვების ორივე ეკრანზე. მისი გამოყენება არ შლის უკვე მიღწეულ პირად სტატისტიკას.
