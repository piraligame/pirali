# WEEKLY+ Alpha 0.01

Standalone Android planner build branch, isolated from PIRALI main. The app source is archived in `.build/source.part*` (base64+XZ). Workflow automatically builds an installable debug APK for Android. 

**Package:** `ge.weeklyplus.app`

**Direct APK after successful build:** https://raw.githubusercontent.com/piraligame/pirali/weekly-plus-alpha001/apks/WEEKLY_PLUS_Alpha_0.01.apk

This is an unsigned-for-store, debug-signed test APK. User data stored locally. Android 8.0+; optimized to test on Samsung Galaxy Z Fold 7. Do not upload this debug APK to Google Play.
