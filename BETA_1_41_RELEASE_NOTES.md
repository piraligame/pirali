# PIRALI Beta 1.41 — Mission label above the minimap

The optional mission label now lives in a dedicated row below the heart display and above the minimap. It no longer covers the map; the map is lowered by precisely the rendered height of the translated mission text plus margins. Resizes, language changes and orientation changes recalculate the layout.

The Developer panel continues to dock under the minimap. Beta 1.40 no-stealth rules and all previous gameplay features, the 7000-point ceiling and Full Route modifiers remain unchanged.

Player and Developer web previews only. Android APK/AAB and Google Play have not been updated.
