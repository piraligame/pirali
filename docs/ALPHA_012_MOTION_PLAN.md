# PIRALI — Alpha 0.12: სიმონასა და ჯარისკაცების მოძრაობა და გრაფიკა

**მიმდინარე გამოსაშვები და მომხმარებლის მიერ დამტკიცებული Alpha:** `alpha-0.11-approved-stable` (Android `versionCode 11`). ეს ვერსია არის Google Play-ზე **პირველად გამოსაქვეყნებელი** თამაშის კანდიდატი, სანამ Google დეველოპერის ანგარიშის ვერიფიკაციას დაასრულებს.

**ისტორიული, ხელუხლებელი ძველი პერსონაჟების რეზერვი:** **alpha old simona 0.09** — Git tag `alpha-old-simona-0.09`, commit `2ee4b41`. აქ Simona და მტრები 0.11-ის ახალ გრაფიკამდე არიან; ზედხედის ორიგინალური ხატვის ფუნქციები ინახება. მნიშვნელოვანი დაზუსტება: ისტორიული 0.09 მენიუს ვერსიაა, ხოლო ამ Git-რევიზიის Android Gradle-ში ჯერ `versionCode 8` / `0.08` წერია. ამიტომ **სარეზერვო წყაროს** ვეძახით და არა დადასტურებულ 0.09 APK-ს. ZIP-არქივი: `PIRALI_ALPHA_RELEASES/RESERVED_OLD_SIMONA/alpha old simona 0.09 - original models.zip`.

**სამუშაო Alpha:** `feat/alpha-012-character-motion`; სრულიად ცალკე საქაღალდე `PIRALI_ALPHA_012_MOTION_WORKSPACE`. **Beta ამ ეტაპზე არ იქმნება და არ ვითარდება; Beta დაიწყება მხოლოდ მომავალში, როდესაც მომხმარებელი უკვე მაღაზიაში გამოქვეყნებულ თამაშს განაახლებს და ამის დაწყებას დაადასტურებს.**

## გაუმჯობესების წესები

- მხოლოდ **ზემოდან ხედი (top-down)**; არ გამოიყენოთ ფრონტალური ან მარჯვნივ/მარცხნივ „წაწვენილი“ ფიგურები.
- სიმონას, რიგითს, მსროლელს, ოფიცერს და გენერალს **არ დავუმატოთ სტატიკური გაშეშებული ხელები და ფეხები**; უკვე არსებული დინამიკური ანიმაციები დავხვეწოთ, მაგრამ თამაშის ფიზიკა არ შეიცვალოს.
- Alpha 0.11-ში მოწონებული წითელი ბატონის დიზაინი შევინარჩუნოთ.
- თითოეული ცვლილება მხოლოდ **ახალ Alpha 0.12-ის ცალკე სატესტო ვებბმულზე** ვაჩვენოთ. APK/AAB, versionCode და Google Play ატვირთვა — მხოლოდ ავტორის ცალკე თანხმობის შემდეგ.

## ფაზა 1 — სიმონა

სიარულისა და სირბილის რიტმი, რბილი შემობრუნება რვა მიმართულებით, ჩოხის ბუნებრივი რხევა, იარაღის დამიზნება, მაუზერის/სანადირო თოფის მცირე უკუცემა, ხმლის მოკლე და მკაფიო მოქნევა, დაზიანებისა და სიკვდილის რეაქციები. არ უნდა შეიცვალოს მოძრაობის სიჩქარე, სიცოცხლე, დარტყმის რადიუსი ან ტყვიების რაოდენობა.

## ფაზა 2 — სამი სახეობის რუსი ჯარისკაცი

**რიგითი:** პატრული → დევნა → ხმლის მოძრაობა → დაზიანება/დაღუპვა.

**მსროლელი:** გაჩერება → დამიზნება → შაშხანის უკუცემა → დაზიანება/დაღუპვა.

**ოფიცერი:** განსხვავებული ნაბიჯის რიტმი, შემობრუნება, პისტოლეტით მიზანში ამოღება და სროლის ეფექტი.

მათი ფორმები და ქუდები ერთსა და იმავე ნახევრად რეალისტურ 2D სტილში დარჩეს, მაგრამ ვიზუალურად გასარჩევი იყოს.

## ფაზა 3 — გენერალი და ბატონი

გენერალს შეტევის წინ მოძრაობით გამოკვეთილი მინიშნება და მეორე ფაზის ვიზუალური აქცენტი; იგივე ბალანსი. ბატონს პანიკური, არათანაბარი გაქცევის ანიმაცია; კვლავ ერთი დარტყმით იღუპება და თამაში სწორად მთავრდება.

## ფაზა 4 — გარემო და ოპტიმიზაცია

ხუთივე ტურის ფონები ცალკე დავხვეწოთ (ჩოხატაური, გოგოლესუბანი, შუა განახლება, უდაბნო, უდაბნოს ეკლესია). ამის წინ არ შეიცვალოს ძირითადი ლეველების განლაგება/კოლიზია. მიზანი: ძლიერი Android-ზე 60 FPS, სხვაგან სტაბილური წარმადობა — ჯერ შესამოწმებელია.

## აუცილებელი რეგრესიის ტესტები

ოთხი ენა, Firebase Top 20-ის რეიტინგი (რეალური შედეგების დაუზიანებლად), ხუთივე ტური, სანადირო თოფი, checkpoint, მთავარი მენიუზე დაბრუნება გამარჯვების/დამარცხებისას. ძველი სიმონას დასაბრუნებელი რეზერვი და Alpha 0.11 ხელუხლებელი.

## პირველადი შესასრულებელი სამუშაო

სიმონას 8-მიმართულებიანი სიარულისა და სირბილის უკეთესი ანიმაციის პირველი ცალკე **Alpha 0.12 Web Preview**. ჯერ სიმონა; შემდეგ ჯარისკაცები. მომხმარებლის მოწონების გარეშე ახალი Alpha არ ჩაითვალოს გამოშვების კანდიდატად.
