# PIRALI Alpha 0.11 — პერსონაჟების რეალური ზედხედის გრაფიკული დახვეწა

მომზადების ეტაპი: 2026-10-19
სამუშაო Git შტო: `feat/alpha-011-topdown-polish`

## რა შეიცვალა
- ახალი კოდი: `js/characters/topdown-polish.js`. მუშაობს **ორიგინალური** `drawPlayer`, `drawEnemy`, `drawBoss` რენდერების თავზე და ინარჩუნებს მათ ჩამორთმევის/დაბრუნების შესაძლებლობით.
- წინა ფრონტალური, დაბრტყელებული `visual-sprites.js` გამორთულია მთავარი `index.html`-დან. ის ისტორიულად დარჩა, მაგრამ თამაშში აღარ იტვირთება.
- სიმონას ზემოდან დანახული ჩოხა, ყაბალახის ზედაპირი, მასრების რიგები, ტყავის სარტყელი, მოკლე ფეხები/ჩექმები, ბუნებრივი მცირე მოძრაობა — ძველი მაუზერისა და ხმლის ხატვის შენარჩუნებით.
- რიგითი, მსროლელი, ოფიცერი: ზედხედის სამხედრო ფორმები, გამოკვეთილი მხრები და მუხრუჭებული ფეხები, სხვადასხვა ქუდი, ელემენტარული აღჭურვილობა. თავდაპირველი იარაღები არ დუბლირდება.
- გენერალი და Rage-ფორმა: გამოკვეთილი სამხრეები, მედლები, ზედხედის ქუდი. თავდაპირველი ხმალი და მისი ვიზუალური ეფექტები უცვლელია.
- **ბატონი არ შეცვლილა** — კოდით სპეციალურად გამორიცხულია (`e.etype === 'landlord'`). გამოსახულებას მფლობელი მოგვაწვდის და მხოლოდ მაშინ ჩავანაცვლებთ.

## სანახავად
- `character-workbench.html` — მარცხნივ ყველა ორიგინალი, მარჯვნივ უკვე დახვეწილი ვერსია. 9 მოდელი/ვერსია × 4 მიმართულება.
- `original-models/` — საწყისი 36 PNG, უცვლელად.
- `polished-models/` — შესაბამისი ახალი 36 PNG და `before-after-gallery.png` საერთო შედარება.
- `index.html` — ახალი ფიგურები **რეალურ თამაშში**, უკუღმა გადახატვის გარეშე.

## კოდის უსაფრთხოება
- თამაშში ნებისმიერ დროს გამორთვა: `PiraliTopdownPolish.enable(false)`, დაბრუნება: `PiraliTopdownPolish.enable(true)`.
- ცვლადები `P.r`, `e.r`, `PIRALI_BALANCE`, სიჩქარე, იარაღების დაზიანება, ტურები, Firebase, რეიტინგი და დაჩექპოინთება არ შეცვლილა.
- ახალი ვიზუალები არ არის უკვე Google Play-ზე ატვირთული. Alpha 0.10-ის ხელმოწერილი APK/AAB, Beta და 0.10-ის release შტო ხელუხლებელია.
- Chrome ავტომატური ტესტი: 4 ენა, გამარჯვება/დამარცხება, მთავარი მენიუ, მე-5 ტურის თოფი/ვაზნები — გავლილია. Android ტელეფონზე ნამდვილი FPS და შეხების კონტროლები ჯერ მომხმარებელმა უნდა შეაფასოს.

## შემდეგი ნაბიჯი
მფლობელის ვიზუალური შეფასება; შემდეგ სიმონას ქუდის/ჩოხის ფერების, მტრების სხეულის ზომისა და ზედხედის პროპორციების დამატებითი დახვეწა; ამის შემდეგ უფრო მდიდარი 4-კადრიანი ანიმაცია. ბატონი დარჩეს ხელუხლებელი მომხმარებლის გამოსახულებამდე.
