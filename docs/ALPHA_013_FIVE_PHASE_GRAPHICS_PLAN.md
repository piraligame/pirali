# PIRALI — ALPHA 0.13 / ხუთი გრაფიკული გაუმჯობესება

**სტატუსი:** 0.13-ზე ცალკე სამუშაო ვერსია. დაწყებულია მხოლოდ ფაზა 1 და ვებტესტი; APK/AAB ჯერ არ შეიქმნას.

**საბაზო:** ხელმოწერილი Alpha 0.12, Git tag `alpha-0.12-signed-release`. ძველი Alpha 0.11 და `alpha-old-simona-0.09` უცვლელი. Beta-ზე ამ ეტაპზე არ ვმუშაობთ.

## 1. მიწა, ბილიკები და გზები — პირველი სამუშაო ფაზა
- ხუთი სხვადასხვა ზედაპირი: ჩოხატაურის მიწა/ფოთლები; გოგოლესუბნის სველი ქვები; შუა განახლების სოფლის ბილიკი და ბორბლის კვალი; უდაბნოს ქვა/ქვიშა; უდაბნოს ეკლესიის მოკირწყლული ისტორიული მისასვლელი.
- რეალური ზედხედის ქვის ცალკეული ფრაგმენტები, ნაპრალები, რბილი კიდეები, მცირე ბალახი და სეზონური მიწის დეტალები. გზა მკაფიოდ უნდა ჩანდეს უკვე არსებული პერსონაჟების უკან.
- **უსაფრთხოება:** რეალური გზის სიგანე, კოლიზია, კამერა, მოძრაობა და რუკის გენერაცია არ შეიცვალოს.
- **მისაღები ტესტი:** 1–5 დონეზე გადართვა, „ახალი გზა ON/OFF“, ეკლესიასთან სწრაფი მისვლა, გვერდიგვერდ ძველი/ახალი შედარება.

## 2. ხეების და ტყის გრაფიკა
- მრავალფენიანი ფოთლის გვირგვინები, ფიჭვის ტოტები, ჩრდილების მიმართულება, ხავსი, გვიმრები და მსუბუქი ქარის მოძრაობა.
- მტრებისა და მოთამაშის შიგნით ხედვა არ გაუარესდეს; დაუსაბუთებელი ახალი დაბრკოლებები არ დაემატოს.
- ცალკე ჩართვა/გამორთვა ვებტესტში.

## 3. სოფლები და ისტორიული გარემოს ობიექტები
- გურული სახლების ზედხედის სახურავები, ღობეები, წყაროს/ჭის დეტალები, თივა, სოფლის ეზოს ქვის ფორმები.
- ისტორიულად შთაგონებული მასალები; ახალი ნახატები **დეკორატიული**, რეალურ დარტყმის/მოძრაობის არეალზე გავლენის გარეშე.
- განსაკუთრებით შუა განახლების ტურში ხილული ხარისხობრივი ნახტომი.

## 4. უდაბნოს ეკლესია — ქვის ფაქტურა და ეზო
- Alpha 0.12-ში მოწონებული ქვის ეკლესიის იგივე ზედხედის არქიტექტურაზე ნატურალური სახურავის ფაქტურა, გუმბათის ნაკერები, საფლავის ქვები და ეზოს კომპოზიცია.
- სტილიზებული ქართული შუასაუკუნეების ატმოსფერო, არა კონკრეტული ძეგლის ზუსტი რეკონსტრუქცია.
- საბრძოლო ფინალი, ბოსის ადგილი და ერთდარტყმიანი ბატონი უცვლელი.

## 5. განათება, ეფექტები და მობილური ოპტიმიზაცია
- ფოთლებისა და კვამლის ეფექტები, სროლის მოკლე განათება, საღამოს გრადიენტები, ფრთხილი ნისლი/მტვერი.
- სტატიკური ტექსტურები წინასწარ დამუშავებული/ქეშირებული; მცირემძლავრიან ტელეფონზე ადაპტური ეფექტები.
- საბოლოო ხუთტურიანი თამაშის, ოთხი ენის, Firebase-სა და FPS-ის ტესტირება რეალურ Android-ზე.

## მკაცრი პირობები
- სიმონა, ჯარისკაცები, გენერალი და ბატონი **ზემოდან** ჩანს. ახალი გაშეშებული ხელები და ფეხები არ ჩანდეს.
- არ ვეხებით `ge.piraligame.pirali`-ს, versionCode 12-ს, უკვე ხელმოწერილ 0.12 APK/AAB-ს, Firebase-ის ქულებს და არსებულ Beta-ს.
- Alpha 0.13 **ჯერ მხოლოდ სატესტო GitHub Pages განშტოებაა**. APK/AAB და Play Console მხოლოდ ავტორის მოწონების შემდეგ.
- ვებტესტში Firebase-ზე ქულების ჩაწერა გამორთული უნდა იყოს; 0.13-ის ლოკალური შენახვის გასაღებები ცალკე სახელებს იყენებს.
