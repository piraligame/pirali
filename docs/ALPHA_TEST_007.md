## კრიტიკული წესი: ერთი და იგივე ხელმოწერა
Android-ზე წინა დაინსტალირებული აპის *წაშლის გარეშე* განახლება შესაძლებელია მხოლოდ მაშინ, როცა **applicationId იგივეა**, **კოდის ნომერი უფრო მაღალია**, და **ხელმოწერის სერტიფიკატი ემთხვევა**.

ძველი, GitHub Actions-ის დროებითი debug გასაღებით ხელმოწერილი APK-ები შესაძლოა **შეუთავსებელი იყოს** ახალ, მუდმივი release key-ით ხელმოწერილ Alpha 0.07-თან. მომხმარებლის ტელეფონზე დაყენებამდე აუცილებელია ხელმოწერის შემოწმება. თუ არ ემთხვევა, Android update-ს არ მიიღებს; პირველ გადასვლაზე ძველი APK-ის წაშლის საჭიროება შეიძლება გაჩნდეს. **წაშლამდე საჭიროა ადგილობრივი პროგრესის დაკარგვის რისკის გათვალისწინება!** გლობალური Firebase რეიტინგი ცალკეა.

**Alpha 0.07 → Alpha 0.08 → ...**: თუ გამოშვებები ამავე keystore-ით დაიხელმოწერა, აპი ჩაიწერება ძველის თავზე და ადგილობრივი მონაცემები შენარჩუნდება.
