# PIRALI ALPHA 0.13 — გზების მსუბუქი გრაფიკის ტესტი

მოთამაშის უკუკავშირი: პირველი Alpha 0.13-ის ახალი გზა ზედმეტად კენჭებით იყო გადავსებული. გზის ასეთი ფაქტურა თვალს ღლიდა.

## შესწორება
- ბუნებრივი Alpha 0.12-ის გზის ფონი, კონტურები, ტექსტურა და მოხაზულობა **შენარჩუნებულია**. მოვაშორეთ ახალი, ზედმეტად მუქი, სქელი ზედა ფენები, რომლებსაც ეკრანზე წრიული ხაზები/ლაქები მოჰქონდა.
- დიდი რაოდენობით წვრილი კენჭების ნაცვლად: ~75–85%-ით შემცირებული ქვების რაოდენობა, უმეტესად ბილიკის ნაპირებთან და ზოგჯერ შუაში, არათანაბარ მონაკვეთებად.
- ყველა ხუთი ტურის ქვის ფერები უფრო ღია, ნეიტრალური, მიწის ან ქვის ბუნებრივ მასალასთან შეთავსებული.
- ქვების ჩრდილები და მკვეთრი კონტურები შესუსტებულია; ზომა ოდნავ შემცირებულია.
- სიმონა დოლიძე, მტრების Alpha 0.13 მოძრაობები, ბატონი, ეკლესია, იარაღი და ხუთივე ტური შენარჩუნებულია.
