# PIRALI — Android-ისთვის მომზადება

ეს ეტაპი ჯერ **არ ქმნის APK-ს ან AAB-ს** და არ აქვეყნებს თამაშს Google Play-ზე. წინასწარ მზადდება მხოლოდ სუფთა ვებ-პაკეტი.

## როგორ შეიქმნას სუფთა პაკეტი ლეპტოპზე
პროექტის მთავარ საქაღალდეში გახსენი ტერმინალი და გაუშვი:

```powershell
npm.cmd run build:android-web
```

შედეგი იქნება `dist/android-web/`: მოქმედი `index.html`, აქტიური JS/CSS მოდულები, გამოსახულებები, მუსიკა/ვიდეო და მონაცემები. იქ **არ მოხვდება** ძველი `js/game.js` (დიდი გამოუყენებელი ვერსია), `Index2.html` და ძველი, არამოქმედი Firebase კონფიგურაცია.

## მომავალი ნაბიჯები
- Android შესაფუთი ტექნოლოგიის (მაგალითად, Capacitor) ცალკე დაყენება, რომლის `webDir` იქნება `dist/android-web`.
- Android Studio პროექტის შექმნა, მინიმალური API დონის/კონტროლის/ეკრანის ორიენტაციის შეთანხმება.
- თამაშის მობილურზე ტესტირება (სენსორული ჯოისტიკი, სროლა, მუსიკა, ვიდეოს autoplay, ონლაინ ლიდერბორდი).
- აპლიკაციის სრული ხატულები, splash screen, უნიკალური application ID, ხელმოწერა (keystore).
- Firebase Realtime Database-ის წვდომის წესების ცალკე აუდიტი (შენახული ქულების დაკარგვის გარეშე).
- კონფიდენციალურობის პოლიტიკა, მშობელთა ასაკობრივი კატეგორია, Google Play-ის სხვა მოქმედი მოთხოვნები და მხოლოდ შემდეგ ხელმოწერილი AAB ატვირთვა.

**შენიშვნა:** `manifest.json`-ში მინიშნებული `assets/icons/icon-192.png`, `assets/icons/icon-512.png` და `assets/icon-192.png` ჯერ არ არსებობს. ეს არის გამოსაშვები ვერსიის მოსამზადებელი დარჩენილი ამოცანა, არ ნიშნავს, რომ მიმდინარე ვებ-თამაში ვერ მუშაობს.

**Firebase:** ვებ-პაკეტის შექმნისას არცერთი ქსელური/მონაცემთა ბაზის ჩაწერის ოპერაცია არ სრულდება.
