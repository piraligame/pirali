# PIRALI Android (Capacitor 8.5.3)

ნატიური Android პროექტი უკვე შექმნილია `android/` საქაღალდეში. მთავარი აპლიკაციის ID: `ge.piraligame.pirali` (შესაძლოა საბოლოო გამოშვებამდე შესაცვლელი იყოს).

## სამუშაო ნაკადი
1. `npm.cmd ci` — დამოკიდებულებების დაყენება.
2. `npm.cmd run build:android-web` — მიმდინარე GitHub Pages-ის ვებ-თამაშის სუფთა პაკეტი `dist/android-web`.
3. `npx.cmd cap sync android` — აქტიური HTML/CSS/JS/asset ფაილების კოპირება ნატიურ Android პროექტში.
4. Android SDK + JDK 21: `cd android; .\gradlew.bat assembleDebug` — შიდა ტესტისთვის APK.
5. `cd android; .\gradlew.bat bundleRelease` — ხელმოუწერელი AAB; **Google Play-ში ასატვირთად საჭირო იქნება მუდმივი ხელმოწერა და პროდუქტის კონფიგურაცია**.

ლეპტოპზე ამჟამად არ არის Java/JDK, Android SDK ან Android Studio. **ადგილობრივი APK/AAB კომპილაცია აქ ჯერ ვერ დასრულდება**. ამის სანაცვლოდ GitHub Actions `.github/workflows/android-internal-test.yml` აწყობს საცდელ APK-სა და ხელმოუწერელ AAB-ს ღრუბელში; GitHub Actions-ის გაშვება #38935696950 **წარმატებით დასრულდა**: შექმნილია შიდა APK (დაახლოებით 6.2 MB) და ხელმოუწერელი AAB (დაახლოებით 5.0 MB). რეალურ ტელეფონზე ინსტალაცია ჯერ არ არის დადასტურებული.

## ჩამოტვირთვა GitHub Actions-იდან
მთავარ GitHub-ზე შედი **Actions → Pirali Android Internal Test → წარმატებული გაშვება → Artifacts** და აირჩიე `PIRALI-Internal-Debug-APK`. ZIP-ში იქნება `app-debug.apk`; ის განკუთვნილია მხოლოდ შიდა ტესტირებისთვის.

`PIRALI-Unsigned-AAB-Preview` არის ხელმოუწერელი პროექტის ბანდლი და **არ არის Google Play-ready**.

## რა არის დარჩენილი
- Android ტელეფონზე ნამდვილი ინსტალაცია და კონტროლების/ეკრანის, ხმებისა და ვიდეოს ტესტირება.
- Firebase ონლაინ სტატისტიკის უსაფრთხო კითხვა/ჩაწერის შემოწმება საცდელი მონაცემებით ან ცალკე ტესტბაზით; მოქმედი Firebase-ის ჩანაწერები არ წაიშალოს.
- ხელმოსაწერი keystore-ის **მფლობელმა თავად შეინახოს უსაფრთხოდ**; არ აიტვირთოს GitHub-ში.
- პროფესიონალური აპის ხატულები, launcher icons, splash-screen, პროდუქტის სახელი, ვერსიები, კონფიდენციალურობა.
- Google Play-ის ტესტირების, განაცხადის, ასაკობრივი კატეგორიის და შემოსავლების/რეკლამების მოთხოვნები.
- არასაჭირო/ძველი `js/game.js` და `Index2.html` გენერირებულ აპის ფაილებში არ შედის.

**შენიშვნა:** `manifest.json`-ში მითითებული ვებ-ხატულების ნაწილი ჯერ არ არის შექმნილი. Capacitor-ის Android ნატიური პროექტი ამ ეტაპზე ნაგულისხმევ ხატულებს იყენებს. საბოლოო Play გამოცემამდე უნდა შევცვალოთ.
