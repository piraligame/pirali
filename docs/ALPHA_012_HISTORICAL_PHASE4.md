# PIRALI Alpha 0.12 — ფაზა 4: ისტორიული ეკლესია

სტატუსი: დამოუკიდებელი სათამაშო Web Preview. დამტკიცებული Alpha 0.11-ის APK/AAB, ძველი Simona 0.09 და Beta არ შეცვლილა. Google Play-ზე არაფერი ატვირთულა.

## ისტორიული კონცეფცია
- უდაბნოს ეკლესიის ძველი მოფანტასტიკური ოქროსფერი ვიზუალის ნაცვლად შექმნილია ქართული შუასაუკუნეების გუმბათიანი ეკლესიის არქიტექტურით შთაგონებული ნაგებობა **პირდაპირ ზემოდან**.
- ჯვაროვანი სახურავი, რვაკუთხა გუმბათი, ქვის წყობის ნაკერები, აღმოსავლეთი აფსიდი, სამხრეთის კარიბჭე, ძველი ქვის ეზო და გალავანი, მოკირწყლული კიბეები.
- ბუნებრივი ფერები. ეს არის **სტილიზებული ისტორიული შთაგონება** და არა კონკრეტული რეალური ძეგლის დადასტურებული არქეოლოგიური რეკონსტრუქცია.

## გარემო
- ხუთივე ტურის გზის კიდეებზე დაემატა პატარა ქვები შესაბამისი გარემოს ტონალობით.
- ზედა ხედვა, თამაშის სავალი ნაწილი, ეკლესიის ცენტრი, მტრების AI, ჩოკპოინტები, ტყვიები, სიცოცხლე და Firebase არ შეცვლილა.
- სიმონას, სამი ჯარისკაცის, გენერლისა და წითელი ბატონის დამტკიცებული ახალი ნახატები შენარჩუნებულია.

## სანახავად
- მხოლოდ ვებტესტში თამაშის დაწყების შემდეგ ჩანს კომპაქტური პანელი „🌲 ტესტი ▾“.
- პანელში 1–5 ღილაკი, „⛪ ეკლესიასთან გადასვლა“, „⛪ ისტორიული ეკლესია ON/OFF“, ასევე ფონისა და მოძრაობის შედარება.
- პირდაპირი გადასვლა მუშაობს მხოლოდ ამ ჩაწერისგან დაცულ საიტზე; ქულები Firebase-ში არ იგზავნება.

## ტესტები
- 4 ენა, გამარჯვება და დამარცხება, მეხუთე ტურის სანადირო თოფი, ისტორიული ეკლესიის გადართვა, საწყისი კოორდინატების უცვლელობა, JavaScript შეცდომების არარსებობა.
- ტელეფონზე რეალური FPS და გრძელვადიანი ტესტირება ჯერ გასაკეთებელია.
- Android-ის Alpha 0.11 უცვლელია; 0.12-ის APK/AAB ჯერ არ შექმნილა.
