# PIRALI Alpha 0.13 — სიმონა დოლიძე და ჯარისკაცების მოძრაობა

## შესწორებული სახელი
მთავარი პერსონაჟის სწორი სახელი არის **სიმონა დოლიძე** (ინგლისურად **Simona Dolidze**). შეცდომით დაწერილი „სიმონა დალიძე“ შეიცვალა Alpha 0.13-ის აქტიურ შესავალში, ქართულ თარგმანში, შიდა აღწერის ეკრანსა და სარეზერვო HTML/JS წყაროებში. ძველი Alpha 0.12 აპლიკაციისთვის არაფერი შეცვლილა.

## მტრის მოძრაობების ვიზუალური დახვეწა
- რიგითი (ხმლიანი ჯარისკაცი): ნაბიჯების რიტმი, მკვეთრი ფორმის ნაოჭები, სხეულის მსუბუქი გადახრა დევნისას.
- მსროლელი: ნელი დამიზნების პოზა, სროლისას მოკლე რეაქცია და უკუცემა, ოდნავ განსხვავებული ნაბიჯის რიტმი.
- ოფიცერი: უფრო შეკავებული ნაბიჯი, სხეულის შებრუნება და ზუსტი სროლის მოკლე ანიმაცია.
- გენერალი: მძიმე ნაბიჯის შთაბეჭდილება, შეტევისას განსხვავებული მხრების მოძრაობა და მიწაზე რბილი მტვრის კვალი.
- ოთხივე მტერს მოძრაობის მიხედვით იცვლება ნაჭრის ნაკეცები, ტანის მცირე დახრა და მიწაზე თითქმის შეუმჩნეველი ნაბიჯის კვალი. პერსონაჟები კვლავ თავიდან ბოლომდე **ზემოდან** ჩანან, არ გვაქვს ნახატზე გაშეშებული დამატებითი მკლავები ან ფეხები.

## უსაფრთხოება და სტატუსი
- რეალური მოძრაობის ფიზიკა, HP, დარტყმა, ტყვიების სიჩქარე, AI გადაწყვეტილებები, კოორდინატები და Firebase არ იცვლება — ახალი მტრის მოდული მხოლოდ **ვიზუალური ანიმაციის** ფუნქციაა.
- GitHub Pages-ის ვებტესტში Firebase-ზე ქულების ჩაწერა დაცულია და ტესტის ადგილობრივი გასაღებები იზოლირებულია.
- headless Chrome-ში გაიარა სახელის, ახალი/ძველი ვიზუალის გადართვის, მტრების, ოთხი ენის, მეხუთე ტურის იარაღისა და თამაშის ფინალის ტესტებმა. JS შეცდომები და Firebase-ის ჩაწერა არ დაფიქსირებულა.
- `tests/alpha013-enemy-motion.cjs` ამოწმებს, რომ ვიზუალური ფუნქციები მტრების რეალურ მონაცემებს არ ცვლიან.
- **Alpha 0.13 ჯერჯერობით მხოლოდ ვებტესტია**. APK/AAB ჯერ არ შექმნილა; Alpha 0.12-ის ხელმოწერილი ფაილები, 0.11 და ძველი Simona 0.09 ხელუხლებელია.
