# PIRALI Alpha 0.12 — ფაზა 3: ხუთივე ტურის გარემოს პირველი გაუმჯობესება

**სამუშაო ვერსია:** Alpha 0.12, branch `feat/alpha-012-character-motion`. ეს არის ცალკე სატესტო WEB ვერსია. **დამტკიცებული Alpha 0.11, ძველი `alpha-old-simona-0.09` და არსებული Beta უცვლელია.** Android APK/AAB ან Play Console-ის ატვირთვა ამ ეტაპზე არ კეთდება.

## შესრულებული გრაფიკული ცვლილებები

1. **ჩოხატაური:** უფრო ღრმა ტყის პალიტრა, ხავსის ტექსტურა, მწვანე ფოთლები და ოქროსფერი მცენარეები.
2. **გოგოლესუბანი:** გრილი ნისლიანი ტყის იერი, ტენიანი მიწა, წყლის გუბეების მსუბუქი ანარეკლი.
3. **შუა განახლება:** ყვითელი სოფლის გზის გარემო, თივის/მარცვლეულის ჯგუფები და მშრალი მიწის დეტალები.
4. **უდაბნო:** მკვეთრად მოყავისფრო-მოწითალო ქვიშის პალიტრა, კლდის ფრაგმენტები და ქარის ზოლები.
5. **უდაბნოს ეკლესია:** ღამის ცივი ლურჯი/მწვანე პალიტრა, საფლავის ქვის დეკორაცია, სანთლები და ეკლესიასთან რბილი ოქროსფერი ნათება.

ეს ყველაფერი **პირდაპირ ზემოდან** ჩანს და შეთავსებულია უკვე მოწონებულ სიმონასთან, ჯარისკაცებთან, გენერალთან და წითელ ბატონთან.

## უსაფრთხოება და შესრულება

- ეს ვერსია იყენებს ცალკე `js/levels/environment-alpha012.js` გრაფიკულ მოდულს; არსებული `drawBG()` არ გადაგვიწერია, მხოლოდ ვიზუალური ფენით შემოვხვიეთ.
- პატარა ტექსტურები თითო ტურისთვის ერთხელ იგენერირება და შემდეგ ქეშიდან იხატება; სათამაშო არეალში არსებული დეკორაციებიც მხოლოდ ახალი რუკის გენერაციისას გამოითვლება.
- ხეების, გზის, ეკლესიის, მტრების, იარაღის, ნივთების და შეჯახების რეალური კოორდინატები არ იცვლება. დეკორაციებს არ აქვთ ახალი hitbox და ისინი ხელს არ უშლიან მოძრაობას.
- სატესტო ვერსიაში ჩანს ცალკე ღილაკები **1–5**, რომლებიც დაუყოვნებლივ გადაგიყვანენ შესაბამის ტურში; **ახალი ფონი ON/OFF** პირდაპირ გაჩვენებს განსხვავებას, **ახალი მოძრაობა ON/OFF** — ანიმაციის შედარებას.
- სათამაშო ქულები სატესტო ვებვერსიიდან Firebase-ზე არ იგზავნება; ონლაინ რეიტინგის რეგულარული წარმოების კოდი უცვლელია.
- ხუთივე გარემოს ავტომატური ვიზუალური გადამოწმება, ოთხი ენის, სიკვდილის, გამარჯვების, თოფის და ვებგვერდის რეგრესია წარმატებულია.
- ტელეფონზე გრძელვადიანი FPS/ბატარეის ტესტი ჯერ საჭიროა; **60 FPS რეალურად დადასტურებული არ არის**.

## შემდეგი ნაბიჯები

ფონების მხატვრული მეორე გავლა: უფრო რეალისტური კლდეები, ტყისა და სოფლის პეიზაჟების დეტალები, გზის კიდეები და საბოლოო ეკლესიის მიდამოები. შემდეგ წარმადობის გაზომვა რეალურ Android-ზე. მომხმარებლის მოწონების გარეშე Alpha 0.11 არ იცვლება და Alpha 0.12-ის APK არ იქმნება.
