# PIRALI Alpha 0.13 — ფაზა: II და III ტურის გარემოს გამიჯვნა

ამ ფაზის მიზანი: ჩოხატაური (1), უდაბნო (4) და უდაბნოს ეკლესია (5) უცვლელად დარჩეს; გოგოლესუბანი (2) და შუა განახლება (3) გახდეს ერთმანეთისა და მეზობელი ტურებისგან მკაფიოდ განსხვავებული, მაგრამ საერთო მხატვრულ სტილში.

## ახალი ვიზუალური მიმართულება
- **II ტური — გოგოლესუბანი:** მწვანე ტყეს ოდნავ გრილი მოლურჯო-ნაცრისფერი ნესტიანი ატმოსფერო დაემატა, ასევე ნამის ლაქები და პატარა გვიმრების ჯგუფები, გზიდან მოშორებით. პირველის მწვანე, ნათელი ხასიათი შენარჩუნებულია თავის ტურში.
- **III ტური — შუა განახლება:** მეოთხე ტურის ნარინჯისფერ უდაბნოსგან განსხვავებული, უფრო მომწვანო-ზეთისხილისფერი, მზიანი სოფლის მინდორი, ბალახისა და თივის მსუბუქი ჯგუფებით. ქვიანი ბილიკი უცვლელად რჩება.
- **I, IV და V ტურები:** ახალი მოდული მათ საერთოდ არ ხატავს; ძველი პიქსელების შედარება ყველა სამ ტურში ტოლია.
- მოძრაობა, კოორდინატები, კოლიზია, გეიმფლეი, მოწონებული სიმონა დოლიძე, ჯარისკაცების ანიმაციები, გენერალი, ბატონი და Firebase არ შეცვლილა.

## უსაფრთხოების შემოწმება
- Chrome-ის გრაფიკულმა QA-მ დაადასტურა: ტური 1/4/5 — **იდენტური ძველი და ახალი `drawBG` პიქსელები**; ტურები 2/3 — განსხვავდება.
- ხუთივე ტური, ოთხივე ენა, სიკვდილის/გამარჯვების UI, ბოლო ტურის სანადირო თოფი, ქვის პოლიტიკა (მხოლოდ III/IV ტურებში) შემოწმებულია. JavaScript runtime შეცდომა და Firebase ჩაწერა არ დაფიქსირებულა.
- გრძელვადიანი რეალური მობილურის FPS ჯერ ცალკე შესამოწმებელია.
- ხელმოწერილი Alpha 0.12 APK/AAB, Alpha 0.11, ძველი Simona 0.09 და Beta ხელუხლებელია. Alpha 0.13 ჯერ მხოლოდ ვებტესტია; APK ან Google Play ატვირთვა არ მომხდარა.
