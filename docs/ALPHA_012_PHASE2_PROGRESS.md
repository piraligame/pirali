# PIRALI Alpha 0.12 — პერსონაჟების ანიმაციის მეორე გაუმჯობესება

**სტატუსი:** ინტერნეტით გასაშვები სატესტო Web Preview. დამტკიცებული Alpha Test 0.11, Play Console-სთვის მომზადებული APK/AAB და ძველი სიმონას 0.09 რეზერვი არ შეცვლილა. Beta-ს არ ვეხებით.

## შესრულებული ცვლილებები

**ფაზა 1 — სიმონა + ჯარისკაცები (დამატებით დახვეწა)**

- უფრო შესამჩნევი 2D ზედხედის მოძრაობა: ჩოხის/მუნდირის ნაკეცები გადაადგილების რიტმს მიჰყვება; სხეული ოდნავ ტრიალებს და მაღალი/დაბალი ნაბიჯის შთაბეჭდილებას ქმნის.
- დინამიკური ანიმაციის ერთიანი კონტროლერი; სიმონას, რიგითს, მსროლელსა და ოფიცერს განსხვავებული ნაბიჯისა და მობრუნების სიჩქარე აქვთ.
- სროლის/იარაღის უკუცემის მოკლე ვიზუალური აქცენტები. არ ჩამატებულა სტატიკური ხელები ან ფეხები.
- კონტროლერის გათიშვით შესაძლებელია Alpha 0.11-ის ზედხედის ანიმაციასთან შედარება.

**ფაზა 2 — გენერალი + წითელი ბატონი (ახალი)**

- გენერლის ტანის/ქუდის უფრო მძიმე ნაბიჯის რიტმი; დამუხტვისა და მეორე ფაზის შეტევების დროს დამატებითი ცხადი გრაფიკული მინიშნება — მისივე თავდაპირველი საბრძოლო ლოგიკის შეცვლის გარეშე.
- ბატონის წითელი სილუეტი, სახე და ულვაში შენარჩუნებულია; დამატებულია გაქცევისას რხევა, მსუბუქი გაწელვა/შეკუმშვა და მოძრაობის უკან ვიზუალური ზოლები.
- ოთხივე მიმართულება შენარჩუნებულია; NPC კვლავ ერთი დარტყმით კვდება.

## ტესტი და უსაფრთხოება

- `tests/motion-alpha012-qa.cjs` — ოთხივე ენის, დამარცხებისა/გამარჯვების, მეხუთე ტურის თოფის, მოთამაშისა და მტრების გრაფიკული ტესტი.
- ვებტესტის ფაილებში Firebase-ის ჩაწერა დაბლოკილია; პროდუქციის Firebase/ლიდერბორდის კოდი ხელუხლებელია.
- მხოლოდ სურათის დახატვის მექანიზმები და სატესტო ვერსიის იარლიყი იცვლება; რეალური hitbox, HP, AI, შეტევის ძალა, ტყვიების რაოდენობა, სიჩქარე და ტურები უცვლელია.
- მობილურზე პირადი ტესტირება და ვიზუალური შეფასება ჯერ საჭიროა.
- სატესტო გვერდზე ღილაკი „ახალი მოძრაობა ON/OFF“ ანიმაციის განსხვავებას პირდაპირ თამაშში აჩვენებს.

## შემდეგი საქმე

დაბალი FPS-ის ტელეფონებზე ტესტი; გენერლის კომბინირებული ეფექტების დატვირთვის გაზომვა; შემდეგ ხუთივე ტურის გარემოს ფონის დახვეწა. არ შევცვალოთ Alpha 0.11-მდე დამტკიცებული სტაბილური გამოცემა მომხმარებლის თანხმობის გარეშე.
