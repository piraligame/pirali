# PIRALI — Stage 2: ტურის პროგრესის შენახვა (2026-10-17)

## რას ინახავს თამაში
თამაშის ყოველი დასრულებული ტურის შემდეგ (`1→2`, `2→3`, `3→4`, `4→5`) ადგილობრივად ინახება *მომდევნო ტურის საწყისი მდგომარეობა*: ტურის ნომერი, სიცოცხლე, ტყვიები, მიმდინარე ქულა და უკვე აღებული ბალახებისა/მედლების რაოდენობა.

შენახვა მხოლოდ **ტურის დასრულებისას** სრულდება; თამაშის შუაში გავლილი მეტრები, ცოცხალი მტრები ან ბოსის ნაწილობრივ დაკარგული სიცოცხლე არ ინახება. დაბრუნებისას მიმდინარე ტური თავიდან გენერირდება; ძველი მარშრუტის/მტრების შემთხვევითი განლაგება შეიძლება განსხვავებული იყოს.

**მთავარი მენიუ**: ღილაკი `გაგრძელება · ტური N — დასახელება` ჩანს მხოლოდ ვალიდური შენახვისას. ღილაკის ტექსტი ოთხივე ენაზე მუშაობს. ჩვეულებრივი `თამაშის დაწყება` ყოველთვის თავიდან იწყებს ახალ, რეიტინგისთვის ვარგის თამაშს. ახალი თამაშის დაწყება ძველ ყველაზე შორს მიღწეულ საგუშაგოს არ შლის.

**Firebase-ის სამართლიანობა**: შენახული ტურიდან გაგრძელება არის *არარეიტინგული რეჟიმი*. მოთამაშე ხედავს ეკრანზე `შენახული ტური` ნიშნულს და შედეგების ბოლოს შენიშვნას. `autoSaveScore()` და `lbPush()` ამ რეჟიმში არ აგზავნის ქულებს ონლაინ TOP 20-ში. თავიდან დაწყებულ სრულ თამაშზე არსებული Firebase მექანიკა უცვლელია.

**უსაფრთხოება**: ინახება მხოლოდ `localStorage['pirali_checkpoint_v1']`, JSON-ის ვალიდირებული მონაცემები (version=1, stage 2–5, სიცოცხლე 1–5, ტყვიები 0–8, შეზღუდული ქულა/ინვენტარი). არ იყენებს ცალკე ანგარიშს, ინტერნეტს, და არც Firebase-ში წერს მონაცემებს. დაზიანებული ფაილი იგნორირებულია. უფრო შორს გავლილი ტური არასოდეს გადაიწერება უფრო დაბალი ტურის მონაცემებით; იმავე ეტაპზე რჩება უკეთესი ქულა.

ბოლო ტურის გამარჯვებისას შენახული საგუშაგო იშლება; დამარცხებისას შენარჩუნდება და ტურის ხელახლა გავლა შესაძლებელი იქნება.

**შენიშვნა**: ეს არის კონკრეტული ბრაუზერის/აპის **ადგილობრივი** შენახვა. სხვა ტელეფონზე ავტომატურად არ გადაიტანება. აპის წაშლამ ან მონაცემების გასუფთავებამ შეიძლება წაშალოს პროგრესი. APK-ის ხელმოწერის კონფლიქტისას **ძველი აპი არ წაშალო**, თუ ადგილობრივი მონაცემების შენარჩუნება გჭირდება.

## ტესტირება
- Chrome ავტომატური ტესტი `test_pirali_stage2_checkpoints.cjs` — ტურის დასრულება, რეალური ფაილის შენახვა და reload-ის შემდეგ გაგრძელება, 4 ენა, 320×568 ეკრანი, სტატისტიკის შენარჩუნება, Firebase-სთვის 0 POST.
- ახალი თამაშით ხელახლა დაწყება ისევ რეიტინგიან რეჟიმში გადადის; ძველ checkpoint-ს არ ანადგურებს.
- დამარცხება checkpoint-ს ინარჩუნებს; ფინალური გამარჯვება შლის.
- დადასტურებულია არასწორი შენახვის მონაცემების უარყოფა და წინა ტურის 2.8 წამით გადადებული ტაიმერის გაუქმება ახალი თამაშის დროს.
- რეგრესია: ხუთი ტური, ოთხი ენა, TOP 20, Android Back/auto-pause, მაუზერი და ფინალის ლოგიკა.
- Android-ზე აპის რეალური ტესტი მომხმარებელთან უნდა დასრულდეს.
