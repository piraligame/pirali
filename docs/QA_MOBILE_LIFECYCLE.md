# PIRALI — Android უსაფრთხოება და მართვა (ეტაპი 1)
განახლებულია: 2026-10-17

## შესრულებული ცვლილებები
- **ავტომატური პაუზა:** Android სისტემის `App.appStateChange(false)`, ბრაუზერის `visibilitychange` და `pagehide` ერთსა და იმავე უსაფრთხო დამმუშავებელს იძახებს; ზარის, ფონისა და ეკრანის ჩაკეტვის დროს მიმდინარე თამაში ჩერდება, ქულა და ტური არ იცვლება.
- **ხელით გაგრძელება:** აპში დაბრუნებისას თამაში თავისით არ აგრძელებს მოძრაობას — ჩანს არსებული პაუზის მენიუ და მოთამაშე აჭერს `გაგრძელება` ღილაკს.
- **გაჭედილი შეხების პრევენცია:** ფონზე გადასვლისას ჯოისტიკის მდგომარეობა, კლავიატურის მიმართულებები და ხანგრძლივად დაჭერილი იარაღის ღილაკები ნულდება.
- **Android Back:** თამაშისას პაუზა; პაუზისას მენიუში გადასვლის დადასტურება; დადასტურებისას დაბრუნება; რეიტინგში დაბრუნება წინა ეკრანზე; ვიდეოინტროში გამოტოვება; მთავარ მენიუში აპიდან გასვლის უსაფრთხო ორნაბიჯიანი დიალოგი.
- **ოთხენოვანი გასვლის დიალოგი:** ქართული, English (US), Русский, 中文.
- ვიდეოინტროს ფონისას გაჩერება და ეკრანზე `▶`-ით ხელით განახლება.
- არ შეცვლილა Firebase-ის წაკითხვის/ჩაწერის მექანიკა, დონეების ბალანსი და სროლა.

## ლოკალური ტესტები
- Chrome DevTools Android App-plugin-ის სიმულაციით: 4 ენა, აპის Back-ის ყველა სცენარი, შეხების გაწმენდა, ზარზე ავტომატური პაუზა, ხელით გაგრძელება, 320px მობილურის დიალოგი — `test_pirali_mobile_lifecycle_20261017.cjs`.
- რეგრესია: ოთხივე ენის მენიუ და HUD, TOP 20 ლიდერბორდი, ხუთივე ტური/ბატონის ფინალი, მაუზერი და „მოი აგერ!“.
- ტესტირებისას რეალურ Firebase-ში ქულა არ დაიწერა.

## რეალურ Android მოწყობილობაზე ხელით დასატესტი
1. დაიწყე ტური და გადაადგილდი. გადადი Home-ზე ან დაბლოკე ეკრანი; დაბრუნებისას დარწმუნდი, რომ თამაში შეჩერებულია და თავისით არ განახლდა.
2. შეამოწმე ფონი/ზარის იმიტაცია/შეტყობინებები და დაბრუნება. ჯოისტიკი გაჩერებული უნდა იყოს.
3. თამაში → Android Back → პაუზა → კიდევ Back → „მთავარ მენიუში?“ → Back-ით უარყოფა.
4. მენიუ → Android Back → „გსურს გასვლა?“ → დარჩენა, შემდეგ საჭიროებისას გასვლის დადასტურება.
5. მენიუ → TOP 20 → Android Back → მენიუში დაბრუნება.
6. ვიდეოინტრო → Android Back → ვიდეოს გამოტოვება.
7. გრძელვადიანი ტესტი: 5–10 წუთი თამაში, ეკრანის სხვადასხვა ზომა, აუდიო, FPS და ბატარეის ხარჯვა.
