# PIRALI Alpha 0.11 — Visual Preview (ნახევრად რეალისტური 2D)

დაწყებული: 2026-10-19. სამუშაო შტო: `feat/alpha-011-visual-preview`.

## რა მუშაობს
- `js/characters/visual-sprites.js` — კოდით გენერირებული, მაღალხარისხიანი Canvas sprite atlas.
- 8 მიმართულება და სიარულის 4 კადრი; GPU-friendly drawImage, sprite cache.
- სიმონა: გამხდარი ჩოხის სილუეტი, ყაბალახი, მასრები, ქამარი, მოძრავი ფეხები, მაუზერი/ხმალი/სანადირო თოფის გამოსახულება.
- რუსი ჯარისკაცების განსხვავებული ადამიანური სილუეტები: რიგითი (ხმალი), მსროლელი (თოფი), ოფიცერი (პისტოლეტი).
- ბრძოლაში უცვლელია სიმონას პარირების ოქროს რგოლი და დაჩქარების ცისფერი ინდიკატორი.
- ძველი დამხატავები შენახულია როგორც `PiraliVisualV2.originalPlayer`, `PiraliVisualV2.originalEnemy`. შედარებისთვის DevTools-იდან გაუშვი `PiraliVisualV2.enable(false)`, დასაბრუნებლად `PiraliVisualV2.enable(true)`.
- `visual-lab.html` — ინტეგრირებული მხატვრული სახელოსნო: 4 პერსონაჟი, მიმართულების მობრუნება, სიარულის ანიმაციის გაჩერება, ზომის შეცვლა.
- საიტის მენიუში იკითხება `ALPHA 0.11 VISUAL PREVIEW`. Android-ის ვერსია/ხელმოწერა **არ შეცვლილა**; APK/AAB არ არის შექმნილი.

## სამუშაო პრინციპი
ვიზუალური ფენა მხოლოდ `drawPlayer` და `drawEnemy`-ს ანაცვლებს. `P.r`, `e.r`, შეტევის არეალი, ჯანმრთელობა, მაუზერის/სანადირო თოფის დაზიანება, AI, ტურები, Firebase რეიტინგი და checkpoint არ იცვლება. გენერალი და ბატონი ამ ეტაპზე ინარჩუნებენ ძველ ვიზუალს, რათა შემდეგ ცალკე დავხვეწოთ.

## სად გავხსნათ
1. `visual-lab.html` — ნახე ოთხივე გრაფიკული პერსონაჟი და მათი ანიმაციები (ინტერნეტის გარეშეც).
2. `index.html` — ახალი გრაფიკის რეალურ თამაშში ტესტირება Windows Chrome-ში.
3. სასურველი დასრულების შემდეგ გადავამოწმოთ ხარისხი Samsung Fold7-ის ეკრანზეც.
4. Alpha 0.10 და Beta უცვლელი რჩება. Google Play-ში ამ ვერსიას ჯერ **არ ვტვირთავთ**.

## შემდეგი მიზნები
- გენერლისა და ფინალური NPC-ს სილუეტების დახვეწა.
- დარტყმის რეაქციის, სროლისა და სიკვდილის sprite/particle ანიმაციების გამდიდრება.
- მოძრაობის 8 მიმართულებიდან 12/16 მიმართულებამდე დეტალიზაცია, მხოლოდ თუ წარმადობა დაუშვებს.
- ტელეფონის რეალურ ეკრანზე უფრო მკაფიო გრაფიკის შემოწმება და შემდგომი კორექტირება.
