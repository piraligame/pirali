# PIRALI — Beta 0.12: პერსონაჟების მოძრაობისა და გრაფიკის გეგმა

**საწყისი, უცვლელი ვერსია:** PIRALI Alpha Test 0.11 (Android versionCode 11, `ge.piraligame.pirali`), Git tag `alpha-0.11-approved-stable`.

**სამუშაო ვერსია:** `feat/beta-012-character-motion` — ცალკე Git worktree. არც Alpha 0.11-ის კოდი, არც მისი APK/AAB, არც არსებული Beta და არც Firebase-ის ბაზა არ შეიცვალოს. პირველ ეტაპზე მხოლოდ Web Preview; ახალი APK მომხმარებლის პირდაპირი თანხმობის შემდეგ.

## ვიზუალური წესი — მთავარია!

სცენა და ყველა პერსონაჟი **პირდაპირ ზემოდან (top-down / bird's-eye)** ჩანს. არ შეიძლება პერსონაჟის ფრონტალური ან ბრტყელი გვერდითი სილუეტით ჩანაცვლება. **ახალ სტატიკურ ნახატში არც ფეხები და არც გაშეშებული ხელები** არ დავაბრუნოთ; ხელების მოძრაობა და იარაღის დამიზნება თამაშის არსებულ, ცალკე ანიმაციაში დარჩეს. ბატონი წითელი, ულვაშიანი, მსხვილი პერსონაჟია — Alpha 0.11-ის მომხმარებლის მიერ მოწონებული სახე არ შეიცვალოს.

## ფაზა 1 — სიმონას მოძრაობა (პრიორიტეტი №1)

1. **Idle**: ძნელად შესამჩნევი სუნთქვა, ჩოხის მცირედი მოძრაობა; პერსონაჟი არ ირხევა/არ ცურავს ადგილზე.
2. **სიარული და სირბილი**: ფეხების ძველი დინამიკური ანიმაცია დარჩეს, მაგრამ სტატიკურ მოდელზე ფეხები არ გამოჩნდეს; ზედხედიდან მხრებისა და ჩოხის რხევა მცირე ამპლიტუდით დაემატოს; ნაბიჯის რიტმი გადაადგილების სიჩქარეს შეუხამდეს.
3. **რვა მიმართულება**: რბილი შემობრუნება და დამიზნება, არ „გატყდეს“ სილუეტი 90°/180°-ის გადასვლისას.
4. **მაუზერი და სანადირო თოფი**: ცალკე იარაღის მიმართულება, უკუცემა და მოკლე ლულის ნათება. ტყვიების რაოდენობა, იარაღების ძალა, სროლის მანძილი უცვლელი.
5. **ხმლით ბრძოლა**: დარტყმა მკაფიოდ წაკითხვადი, მოკლე ჭრილის ეფექტით; თავდაცვის/პარირების თავდაპირველი ეფექტი ხელუხლებელი.
6. **დაზიანება და დაღუპვა**: მოკლე რეაქცია, ზომიერი გამჭვირვალობა; არ გაქრეს მთავარი მენიუს ღილაკი სიკვდილის შემდეგ.

**მისაღები პირველი დემო:** მხოლოდ Simona; გვერდიგვერდ Alpha 0.11 / Beta 0.12 ვიზუალური შედარება + თამაშის კლავიატურით და ტელეფონზე მობილური კონტროლით ტესტი.

## ფაზა 2 — რიგითი, მსროლელი და ოფიცერი

- **რიგითი (ხმალი):** ფრთხილი პატრული, დევნის დაწყების პოზა, ხმლის მოქნევა, დარტყმის რეაქცია, დაღუპვა.
- **მსროლელი (შაშხანა):** პოზიციაში გაჩერება, დამიზნება, სროლის უკუცემა, მოკლე ლულის ნათება, ვაზნების ეფექტი მხოლოდ ვიზუალური.
- **ოფიცერი (პისტოლეტი):** მკვეთრი, თავდაჯერებული შემობრუნება, სხვა მოძრაობის რიტმი, ბრძანების/გაფრთხილების ჟესტი ზედხედის შესაბამისი მცირე ეფექტით.
- ცალკე, ერთმანეთს არ დამსგავსებული მუნდირები/ქუდები და საფრთხის წაკითხვადი ანიმაციები. რეალური AI და შეჯახების რადიუსი უცვლელი.

**მისაღები მეორე დემო:** თითოეული ჯარისკაცის ოთხივე ძირითადი მიმართულება, დარტყმა/სროლა/დაღუპვა, FPS და კონტროლი.

## ფაზა 3 — გენერალი და ბატონი

- **გენერალი:** ბრძოლის დაწყებამდე მოძრაობის მინიშნება (telegraph), შეტევა, მეორე ფაზის განსხვავებული რიტმი და ფერის ზომიერი აქცენტი; სიცოცხლე, ბალანსი და შეტევის არეალი არ შეიცვალოს.
- **ბატონი:** პანიკური, არათანაბარი გაქცევა/შემოტრიალება, წითელი სახისა და ულვაშის ამოცნობადობა; კვლავ ერთი დარტყმით იღუპება და თამაში სწორად მთავრდება.

## ფაზა 4 — გრაფიკის მცირე დეტალები

- ჩოხის ნაკეცების რბილი განათება, ქუდების მოცულობა, ბუნებრივი ჩრდილი მიწაზე, რხევის მინიმალური ამპლიტუდა.
- მხატვრული მიმართულება: მკვეთრად წაკითხვადი ზედხედი, **არანაირი ზედმეტი გრძელი ხელები, ფეხები ან გვერდიდან „წაწვენილი“ ფიგურები**.
- პერსონაჟის დეტალი შეესაბამებოდეს მობილურის ჩვეულებრივი ზომის ეკრანზე ხილვადობას. ფონი და ხუთივე ტურის გარემო — ცალკე სპრინტი, ჯერ არ შევეხოთ.

## ტექნიკური დაცვა / ტესტი

- ანიმაცია `deltaTime`-ზე; სიმძლავრეზე დამოკიდებული რიტმი, მკვეთრი FPS რყევების გარეშე.
- ხარისხის მიზანი: 60 FPS ძლიერ ტელეფონზე; დაბალი სიმძლავრის მოწყობილობაზე სტაბილური 30 FPS ან ადაპტური ვიზუალური ეფექტები. ეს არის **სამიზნე**, არა ჯერ დადასტურებული შედეგი.
- Firebase-ის ონლაინ რეიტინგი და ყველა 4 ენა (`ka`, `en-US`, `ru`, `zh`) ხელუხლებელი.
- ხუთივე ტური, სანადირო თოფის ასაღები ობიექტები, გამარჯვება/დაღუპვა და მთავარ მენიუზე დაბრუნება უნდა გაგრძელდეს იმავე წესებით.
- ყოველი მნიშვნელოვანი კადრისა და ბეტა დემოს შემდეგ შედარება Alpha 0.11-სა და მომავალი Beta 0.12-ს შორის.
- მხოლოდ `feat/beta-012-character-motion`-ში ცვლილებები; stable tag არ გადაწერო.

## შემდეგი მყისიერი ამოცანა

**სიმონა — მოძრაობის პირველი ბეტა დემო:** 8 მიმართულებით შემოტრიალების, სიარულისა და სროლის ვიზუალური დახვეწა **Alpha 0.11-ის თანდართული, არსებული მოდელის საფუძველზე**. წარდგენა მხოლოდ ცალკე ვებ-ბმულით, APK/AAB-ის შექმნის გარეშე.
